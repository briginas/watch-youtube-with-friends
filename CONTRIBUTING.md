# Участие в разработке

Ошибки и предложения можно обсуждать в
[GitHub Issues](https://github.com/briginas/watch-youtube-with-friends/issues).
Для ошибки укажите версию расширения и Chrome, шаги воспроизведения, ожидаемый
и фактический результат. Удаляйте из отчётов токены, приглашения в приватные комнаты
и персональные данные.

## Подготовка

Используйте Node.js из `.nvmrc`, выполните `npm ci` и следуйте
[быстрому старту](README.md#быстрый-старт). Для Firebase Emulator Suite нужен JDK 21+.
Настройки своего сервера создавайте по [инструкции](docs/configuration.md);
`.env.*` и `.local/` не включаются в Git.

## Изменения и pull requests

- Соблюдайте [процесс разработки](docs/development.md) и [AGENTS.md](AGENTS.md).
- До изменения поведения создайте или продолжите OpenSpec change с требованиями
  и сценариями проверки. Для документации и внутренних правок без изменения
  поведения отдельный change не нужен.
- В PR опишите проблему, результат и выполненные проверки. Обновите CHANGELOG,
  если изменение заметно пользователю или участникам проекта.
- После реализации завершите задачи change, синхронизируйте specs и архивируйте его.
- Не включайте зависимости, сборки, локальные настройки или секреты.

## Проверки

```sh
npm run typecheck
npm test
npm run build
npm run spec:validate
npm run repo:audit
```

Browser- и интеграционные проверки выбирайте по затронутым сценариям из
[процесса разработки](docs/development.md). CI также запускает browser smoke
и Firebase Emulator Suite; проверка настоящего YouTube выполняется отдельно.
Версию повышайте при подготовке релиза по [инструкции выпуска](docs/release.md).
