# Пример развёртывания

Все project IDs вымышлены. Файлы показывают структуру инвентаря, последовательность
release descriptors и неизменяемые снимки контракта. `provenance: fixture` не означает
существующий сервер. Скопируйте через `npm run config:init`, затем заполните своё
окружение по [инструкции](../../docs/configuration.md). Никогда не редактируйте этот
пример, подставляя рабочие credentials или реальные IDs; используйте `.local/deployment`.
