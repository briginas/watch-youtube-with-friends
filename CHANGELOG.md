# Changelog

Здесь фиксируются заметные изменения проекта. Номер версии относится к расширению;
совместимость backend определяется отдельно. Публикация исходников не означает
публикацию этой версии в Chrome Web Store.

## 0.2.6 — 2026-11-05

- Исправлена компоновка списка комнат: индикатор подключения и отмена остаются в одной строке.
- Подготовлен production-пакет для обновления Chrome Web Store; используется прежнее поколение backend `prod-v1`.
- Добавлены MIT LICENSE, инструкция для участников и метаданные GitHub-репозитория.

## 0.2.5 — исходное публичное состояние, 2026-11-05

Первый публичный снимок включает возможности и исправления, накопленные до версии
0.2.5. Это сводка состояния, а не перечень изменений только последнего patch-релиза.

### Возможности

- Совместный просмотр на обычной странице YouTube: play/pause, перемотка и скорость.
- Создание комнат, приглашения, список сохранённых комнат и присутствие участников.
- Явная смена общего видео, локальный просмотр другого ролика и возврат в комнату.
- Компактная панель комнаты на странице YouTube и управление комнатами из popup.
- Действия «В этой вкладке», «Перейти» и «Открыть» в зависимости от положения комнаты.
- Ограниченные по времени попытки подключения, отмена входа и ручной повтор.
- Версия в popup и метка локальной сборки в деталях расширения.

### Надёжность и разработка

- Упорядочивание конфликтующих перемоток и защита активного локального жеста.
- Восстановление после потери связи без очереди устаревших offline-действий.
- Локальные громкость, качество и субтитры не передаются другим участникам.
- Раздельные поколения backend, реестр совместимости и инструменты выпуска.
- OpenSpec, unit- и browser-тесты, Firebase Emulator Suite и GitHub Actions CI.
- Обезличенные отчёты проверок и примеры конфигурации; настройки оператора остаются локально.
