# Материалы Chrome Web Store 0.2.6

Два снимка настоящего YouTube с production-сборкой 0.2.6, созданные 2026-11-05:

- `room-compact-0.2.6-1280x800.jpg` — свёрнутая панель комнаты.
- `room-expanded-0.2.6-1280x800.jpg` — раскрытая панель со статусом и участником.

Версия подтверждена в chrome://extensions и popup. Это реальная сохранённая комната
с одним участником; снимки не подтверждают двухпрофильный smoke или синхронизацию.
Использована сборка из ZIP 0.2.6, SHA-256
`9119f7b581f659ec465759fdaef30197a8b1df8a7ae6c79e9fd699bcbb2dc438`.

Снимки окна обрезаны до области страницы и уменьшены до 1280×800; содержимое
интерфейса не дорисовано. Формат JPEG sRGB, три канала, без alpha. Адресная строка,
другие вкладки, UID, room secret, токены и диагностические панели исключены.
Снимки заменяют старый screenshot в draft Chrome Web Store.

## Исторические материалы 0.1.0

`room-1280x800.png` — настоящий YouTube и панель release-версии с двумя участниками,
два изолированных Chromium profiles, production Firebase. Последний снимок создан
headed production smoke 2026-11-04. Viewport без адресной строки; поле приглашения скрыто.
UID, room secret, токены и диагностические панели на изображении отсутствуют.

Размер 1280×800, PNG RGB без alpha. Иконка Store — `public/icon/128.png`, 128×128;
исходник оригинальной иконки — `assets/icon.svg`. Генератор — `scripts/icons.mjs`.
Первоначальный screenshot в dashboard был снят с того же ZIP 0.1.0 во время предыдущего production smoke;
последующий повтор smoke обновляет локальное изображение, но не загруженный ZIP.

Требования к изображениям сверены с официальной документацией:
https://developer.chrome.com/docs/webstore/images
