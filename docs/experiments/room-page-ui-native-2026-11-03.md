# Room page UI: проверка в обычном Chrome, 2026-11-03

Использованы два независимых профиля Watch Together QA A/B в обычном Google Chrome 156.0.8078.74 arm64, macOS 27.2. Оба профиля загрузили одну unpacked cloud QA-сборку из `.output/cloud/chrome-mv3`. Использован существующий Firebase QA-проект; Hosting/Rules не развёртывались ради UI. Комната создана на обычном записанном видео Big Buck Bunny. В отчёте и скриншотах нет ссылок-приглашений, ключей, UID или Auth.

## Границы подтверждения

Отказ clipboard в обычном Chrome не возник: существующее разрешение `clipboardWrite` позволяло копировать. Управляемый browser-тест проверяет отклонённый Promise, read-only ссылку и отсутствие ложного успеха; это не выдаётся за естественный native-отказ. Точные 640×480 CSS px с названием в 200 символов проверяются Playwright; в обычном Chrome отдельно подтверждены четверть экрана и масштаб 200%. Естественная реклама не встретилась и остаётся отдельной отложенной проверкой. Native-сессия не измеряла playback revision; отсутствие команд от UI проверяется emulator suites.

Уточнение приёмки от 2026-11-03 согласовано пользователем: успешное копирование принимается по этим native-наблюдениям, обработка отказа и показ ручной ссылки — по существующему browser-тесту с искусственным отказом `navigator.clipboard.writeText()`. Ожидание естественного отказа исключено из критерия завершения `room-page-ui`. Естественный отказ и ручное копирование в обычном Chrome остаются ненаблюдавшимися; это уточнение не добавляет новых native-результатов.

После последних исправлений повторно выполнен `npm run build:cloud` и перезагружено расширение в обоих профилях. В A повторены создание, раскрытие мышью, копирование и выход через страницу с очисткой title. В B загрузка watch после прежнего выхода не восстановила комнату. Оба QA-видео оставлены на паузе. Основная матрица и первые семь скриншотов получены до заключительных исправлений дедупликации presentation-сообщений и обработки ошибок. Проверка малого окна и её скриншот выполнены на финальной сборке. Финальный smoke не повторяет всю матрицу. После дополнительного исправления нормализации пробелов title cloud-сборка пересобрана и перезагружена в обоих профилях; этот крайний случай проверяется unit/browser/live-тестами, без повторного native-прогона всей матрицы.
