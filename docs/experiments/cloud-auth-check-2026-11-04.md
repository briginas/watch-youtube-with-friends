## Результат

В текущем окружении ошибка не воспроизводится. Прямой запрос Anonymous Auth, вход из настоящего action popup, создание облачной комнаты, повторное подключение после reload расширения и открытие сохранённой комнаты прошли успешно. Решение пользователя от 2026-11-04: поскольку ошибка не воспроизводится, считаем её отсутствующей. Вопрос закрыт; облачный Auth не считается открытой проблемой или препятствием для дальнейшей приёмки MVP.

Исходный код, `.env.cloud`, настройки Firebase и серверные Rules не изменялись; деплоя не было. Изменение OpenSpec не создавалось: поведение продукта не менялось.

## Ограничения

Проверен один профиль на одном компьютере. Обновление токена после истечения срока действия, второй профиль, независимые сети, приглашение гостя и синхронизация между участниками в эту проверку не входили. Сохранение того же UID после reload отдельно не измерялось.

При повторении сбоя нужно сохранить Firebase error code и HTTP status неудачного Auth-запроса в DevTools extension-документа, исключив API key, UID, токены и секрет комнаты. Общее сообщение popup само по себе не позволяет отличить отказ Firebase от ошибки запуска session-документа: текущий `App.tsx` использует его для нескольких видов исключений.
