# Список комнат: проверка в обычном Chrome, 2026-11-03

Проверка выполнена через интерфейс установленного Google Chrome, без Playwright/CDP. Два существующих независимых профиля «Watch Together QA A» и «Watch Together QA B» на одном Mac и одном внешнем сетевом маршруте. Chrome 156.0.8078.74 arm64, macOS 27.2. Использована cloud-сборка `.output/cloud/chrome-mv3`, обновлённая в обоих профилях через Reload установленного расширения.

Backend: QA-проект `example-qa`, RTDB europe-west1. [Hosting приглашений](https://example-qa.web.app/). Опубликованы только Database Rules; hosting и Auth не менялись. Активные Rules прочитаны через Firebase CLI и структурно совпали с `.output/cloud/database.rules.json`; SHA-256 канонического JSON: `5801d510c1ecb462caf65627f28e69c41cf436ebb9a628a0ed687715e4228371`.

Все комнаты созданы заново с обязательной metadata. Ниже они обозначены R1/R2; секретные ключи, приглашения и UID в отчёте не сохраняются.

| Действие | Наблюдаемый результат |
| --- | --- |
| В A открыто реальное видео `aqz-KE-bpKQ`, через настоящий popup создана R1 | Появились приглашение, один участник и запись «Big Buck Bunny 60fps 4K - Official Blender Foundation Short Film». |
| В A открыта extension-страница вне YouTube, затем настоящий action popup | Видны подсказка открыть YouTube и сохранённая R1 одновременно. |
| Нажато «Открыть» в этом popup | Фокус вернулся в существующую watch-вкладку. В tab bar осталась одна watch-вкладка, участник остался один. |
| В B открыто приглашение R1 и нажато «Присоединиться» | Открылась watch-вкладка, индикатор показал два участника. В списке B появилось то же название. |
| В B нажато «Убрать из списка» при открытой R1 | Список стал пустым; popup продолжил показывать подключённую комнату и двух участников. Просмотр не завершился. |
| В B открыта вторая вкладка того же видео и создана R2 | Новое приглашение, одна запись с тем же названием и один участник в R2. Вкладка R1 продолжила работать отдельно. |
| В R2 нажата Pause | Плеер показал Play, индикатор — «На паузе · 88.5 с · ×1». В A R1 сохранила воспроизведение: кнопка Pause, состояние «Воспроизводится», два участника. |
| В A закрыта watch-вкладка R1, открыт popup вне YouTube и нажато «Открыть» | R1 сохранилась в списке; после серверного чтения открылась новая watch-вкладка, индикатор показал «Комната подключена» и двух участников. |
| После последней правки обработки ошибок заново собрана cloud-сборка, тестовые watch-вкладки закрыты, расширение Reload в A и B | Каждый профиль сохранил собственный каталог: R1 в A и R2 в B; удалённая из B запись R1 не вернулась. |
| В окончательной сборке B нажато «Открыть» для R2 после закрытия всех watch-вкладок | Открылась одна watch-вкладка; «Комната подключена», один участник и прежнее состояние «На паузе · 88.5 с · ×1». После проверки вкладка закрыта, запись осталась. |

Это функциональная приёмка списка и жизненного цикла комнат. Она не измеряет p95 синхронизации, не проверяет независимые сети/страны и не повторяет приёмку естественной рекламы. Перезапуск всего Chromium, конкурентное открытие, повреждение каталога и управляемые ошибки storage/сети проверяются отдельно в `tests/room-transport/catalog.spec.ts`.
