# Панель: обычный Chrome, 2026-11-04

Google Chrome 156.0.8078.74 arm64, macOS 27.2, профиль Watch Together QA A. Настоящий YouTube: Big Buck Bunny, `aqz-KE-bpKQ`. Использована свежая unpacked transport-сборка, локальные Auth/RTDB/Hosting emulators. Страница и плеер YouTube не подменялись. После reload расширения watch-документ открыт заново; тестовая комната создана через настоящий popup.

| Действие | Наблюдение |
| --- | --- |
| Штатная кнопка YouTube Full screen | Видео перешло в fullscreen; панель отсутствовала на экране и в AX-дереве. Префикс комнаты сохранился в title окна. |
| Escape | Панель вернулась раскрытой с одним участником, кнопки копирования и выхода доступны. |
| Window → Move & Resize → Top Left | В четверти экрана раскрытая панель полностью помещалась в окне; выход доступен. Размер screenshot окна 1352×848 Retina px; это не утверждение о точных 640×480 CSS px. |
| Попытки drag через `App.drag(from, to)` | Перемещение не подтверждено. Несколько горизонтальных и диагональных попыток оставляли панель на месте; часть переключала раскрытие. Видимый курсор оставался около начальной точки. Причина не установлена: эти попытки нельзя считать успешным native drag или доказательством неисправности пользовательской мыши. |
| Завершение QA | Выход через панель снял title/панель. Размер окна восстановлен через Return to Previous Size. Временная transport-сборка отключена, видео поставлено на паузу. Исходная cloud-сборка оставлена включённой. |

Попытка первоначальной проверки через cloud-сборку остановилась на ошибке Anonymous Auth. Поэтому успешные наблюдения выше относятся к локальным эмуляторам; cloud Auth этим изменением не исправлялся и не считается проверенным.

В последующей отдельной [проверке облачного Auth 2026-11-04](cloud-auth-check-2026-11-04.md) вход, создание комнаты и повторное подключение на свежей сборке прошли успешно. Прежняя ошибка не воспроизведена; по решению пользователя от 2026-11-04 считаем её отсутствующей, вопрос закрыт. Эти результаты не меняют окружение исходной проверки панели.

В отдельном видимом Chromium 156.0.8078.4 на настоящем YouTube drag свёрнутой и раскрытой панели прошёл реальными mouse-событиями; fullscreen включался и выключался штатной кнопкой YouTube, положение восстановилось, playback остался прежним. Это дополнительная проверка реального сайта. Обезличенная геометрия: [youtube observations](room-panel-position-youtube-2026-11-04.json).

**Ручная проверка пользователя:** в ответ на оставшийся пункт проверки drag в обычном Chrome пользователь сообщил: «работает, я попробовал». Это независимое ручное подтверждение закрывает оставшийся пункт 3.2. Версия браузера и профиль этой пользовательской проверки отдельно не сообщались; версия выше относится к QA-сессии агента. Неудачные попытки через инструмент управления не переобозначаются как успешные.
