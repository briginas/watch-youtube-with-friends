# Архитектурные решения

Дата начала: 2026-11-02.

| ADR | Статус | Решение |
| --- | --- | --- |
| [0001](0001-extension-toolchain.md) | Принято | WXT, TypeScript, React и средства проверки |
| [0002](0002-firebase-room-backend.md) | Принято для технического прототипа | Firebase RTDB/Anonymous Auth в extension-origin документе вкладки просмотра |
| [0003](0003-native-youtube-player.md) | Принято для технического прототипа | Isolated DOM-адаптер с узким MAIN-world setter скорости; естественная реклама отложена пользователем |
| [0004](0004-production-generations.md) | Принято, rollout отдельно | Backend по поколениям и постоянный служебный Hosting |

«Принято» означает согласованный выбор. «Предложено для проверки» означает рабочую гипотезу прототипа; результаты эксперимента обязательны до принятия.

Каждый ADR хранит контекст, решение, альтернативы, последствия и условие пересмотра. Детали отдельного изменения находятся в его design.md, а наблюдаемое поведение — в OpenSpec specs. При изменении важного принятого решения создаётся новый ADR со ссылкой на заменённый.
