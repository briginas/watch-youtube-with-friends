# ADR-0001: Инструменты разработки расширения

Дата: 2026-11-02  
Статус: принято по согласованию в чате.

## Контекст

Проект — Chrome-расширение с popup, управлением вкладками, небольшим интерфейсом поверх YouTube и синхронизацией нескольких клиентов. Нужно быстро проверять интеграцию с реальным сайтом и воспроизводимо собирать Manifest V3.

## Решение

- WXT для структуры, сборки и development workflow расширения.
- TypeScript для логики, React и CSS Modules для интерфейса.
- Shadow DOM для изоляции стилей интерфейса на странице.
- Zod для проверки входящих сообщений и состояния.
- Vitest для алгоритмов синхронизации и Playwright для браузерных сценариев.
- Firebase Emulator Suite для интеграционных проверок Auth, RTDB и Security Rules.
- OpenSpec для разработки небольшими изменениями; PRD и ADR сохраняются рядом с кодом.
- OpenSpec CLI устанавливается локально; package-lock.json фиксирует зависимости. Зависимости самого расширения добавляются в рамках первого change.

## Альтернативы

Plasmo предоставляет готовую инфраструктуру расширения, но для этого проекта выбран WXT с Vite и средствами внедрения UI. CRXJS позволяет работать непосредственно с Vite, но потребует самостоятельно организовать больше частей проекта. Чистые browser APIs с собственной сборкой увеличат первоначальную настройку.

## Последствия и проверка

Бизнес-логика синхронизации отделяется от WXT/React и адаптера YouTube: её можно проверить без сайта. Начальный браузерный стенд использует bundled Chromium с отдельными persistent profiles; проверки в обычном Chrome выполняются отдельно.

Пересмотр нужен, если сборка или ограничения framework мешают работе прототипа на реальном YouTube. Наличие инструментов в ADR не означает, что они уже установлены и настроены.
