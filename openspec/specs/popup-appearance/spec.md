# popup-appearance Specification

## Purpose

Определяет согласованное с выбранным брендингом оформление popup, доступность его действий и сохранение личного выбора светлой или тёмной темы.

## Requirements

### Requirement: Единая компоновка двух тем

Popup SHALL по умолчанию использовать светлую сливочную тему с компактной плюшевой обложкой без отдельной верхней строки с иконкой и заголовком. Переключатель темы MUST находиться справа сверху на обложке, версия приложения — справа снизу, с читаемыми подложками. Тёмная сливовая тема MUST сохранять ту же компоновку, отступы, подписи и действия; различаются только цвета и декоративные акценты.

#### Scenario: Первый запуск

- **WHEN** пользователь открывает popup без сохранённого выбора
- **THEN** отображается светлая тема и компактная обложка без отдельной строки брендинга
- **AND** оформление системы не переопределяет светлую тему

#### Scenario: Переключение

- **WHEN** пользователь переключает тему
- **THEN** меняется палитра popup без смены комнаты, отправки playback-команд или потери раскрытых подробностей
- **AND** взаимное расположение основных элементов сохраняется

#### Scenario: Управление и версия на обложке

- **WHEN** пользователь открывает popup в любой теме при ширине 400 или 336 CSS px
- **THEN** переключатель находится внутри правого верхнего угла обложки, версия текущего пакета — внутри правого нижнего
- **AND** оба элемента читаемы, не перекрывают друг друга и не создают дополнительную строку над обложкой
- **AND** переключатель доступен даже вне YouTube и без активной комнаты

#### Scenario: Ошибка сохранения темы на компактной обложке

- **WHEN** сохранение выбранной темы завершается ошибкой
- **THEN** сообщение об ошибке появляется под обложкой и не перекрывает переключатель или версию
- **AND** переключатель остаётся доступным

### Requirement: Локальный выбор темы

Popup SHALL сохранять выбранную тему в текущем браузерном профиле и восстанавливать её при повторном открытии. Ошибка чтения SHALL приводить к светлой теме; ошибка сохранения MUST оставлять переключение работоспособным в открытом popup и сообщать, что выбор не сохранён.

#### Scenario: Повторное открытие и отдельный профиль

- **WHEN** пользователь выбрал тёмную тему и повторно открывает popup в том же профиле
- **THEN** применяется тёмная тема
- **AND** другой профиль без сохранённого выбора использует светлую тему

#### Scenario: Недоступные или повреждённые настройки

- **WHEN** сохранённое значение неизвестно либо чтение хранилища завершилось ошибкой
- **THEN** popup открывается в светлой теме, его действия остаются доступны

#### Scenario: Отказ сохранения

- **WHEN** пользователь переключает тему и сохранение завершилось ошибкой
- **THEN** выбранная палитра применяется в открытом popup и доступно пояснение об ошибке сохранения
- **AND** пользователь может снова переключить тему

### Requirement: Доступность оформления popup

Обе темы SHALL иметь читаемые текст, состояния ошибок и фокус клавиатуры. Переключатель MUST иметь доступное имя и состояние, работать с клавиатуры и оставаться доступным без активной комнаты. Основные интерактивные элементы SHALL иметь область нажатия не меньше 44×44 CSS px.

#### Scenario: Клавиатура и узкое окно

- **WHEN** пользователь открывает popup вне YouTube при ширине 336 CSS px и переключает тему клавиатурой
- **THEN** тема меняется с видимым фокусом и корректным доступным состоянием переключателя
- **AND** длинные названия и сообщения переносятся, действия доступны без горизонтальной прокрутки

### Requirement: Полосы прокрутки в палитре popup

Вертикальные полосы прокрутки окна popup и списка комнат SHALL использовать различимые цвета ползунка и дорожки из выбранной темы. При переключении темы их оформление MUST обновляться в открытом popup, сохраняя доступность содержимого прокруткой.

#### Scenario: Переполнение окна и каталога

- **WHEN** содержимое окна popup и списка комнат требует вертикальной прокрутки в светлой или тёмной теме
- **THEN** полосы обеих областей соответствуют палитре темы
- **AND** пользователь может прокрутить каждую область до нижнего содержимого без горизонтального переполнения при ширине 400 и 336 CSS px

#### Scenario: Смена темы при переполнении

- **WHEN** пользователь переключает тему в popup с вертикальной прокруткой
- **THEN** цвета ползунков и дорожек обеих областей меняются на палитру выбранной темы без переоткрытия popup
