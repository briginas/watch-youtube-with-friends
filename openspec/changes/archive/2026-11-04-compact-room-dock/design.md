# Design

## Context

Док работает в существующем extension iframe. Content script получает размеры панели и удерживает её в границах окна. Приглашение доступно только внутри iframe.

## Goals / Non-Goals

**Goals**

- Оставить копирование доступным рядом с кнопкой раскрытия и сохранить перемещение за заголовок.
- Разместить прокручиваемые подробности над доком и сохранить доступ к его кнопкам при ограниченной высоте.

**Non-Goals**

Публикация в Chrome Web Store и миграция данных выходят за рамки change.

## Decisions

- Две отдельные кнопки в доке разделяют раскрытие с перетаскиванием и запись приглашения в clipboard. Кнопка раскрытия остаётся областью захвата мыши.
- Свёрнутый док запрашивает ширину 256 px, раскрытый — 320 px. Существующий протокол отображения ограничивает размеры по viewport, а подробности прокручиваются внутри панели.
- Тёмная палитра сохраняет установленную тему iframe. Для штатного совместного просмотра достаточно точки с текстовой подсказкой. Нештатные состояния остаются видимым текстом.
- При успешной записи док показывает временное подтверждение. При отказе он раскрывает подробности и выделяет ссылку в доступном только для чтения поле.

## Risks / Trade-offs

- Изменение высоты и ширины при раскрытии влияет на доступную область перетаскивания. Проверяем раскрытие, края окна и fullscreen в Chromium.
- Сценарии на локальном стенде подтверждают работу интерфейса и iframe. Внешний сайт в этих сценариях заменён тестовой страницей.

## Migration Plan

Версия 0.2.2 задаётся в package.json и lockfile. WXT переносит версию в манифест. Для данных комнат шагов миграции нет.
