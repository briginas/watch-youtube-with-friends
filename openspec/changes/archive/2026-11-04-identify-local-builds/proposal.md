# Proposal

## Why

Версия релиза в Chrome не позволяет различить несколько локальных сборок из разных состояний исходников. Повышение версии после каждой правки смешивает локальные проверки и подготовку релиза.

## What Changes

- Локальная сборка получает отображаемую метку с версией, Git-коммитом и временем сборки.
- Версия в `package.json` и `package-lock.json` повышается при подготовке релиза по совокупности изменений с прошлого выпуска.

## Capabilities

### New Capabilities

- `extension-build-identity` — идентификация локальных сборок расширения.

### Modified Capabilities

## Impact

Конфигурация WXT и правила разработки. Сценарии продукта и контракт с backend сохраняются.
