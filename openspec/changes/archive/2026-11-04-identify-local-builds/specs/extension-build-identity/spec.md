# Spec Delta

## Purpose

Идентификация установленной локальной сборки расширения и её исходного коммита.

## ADDED Requirements

### Requirement: Отображаемая метка локальной сборки

Сборка основного расширения для локальной установки или QA SHALL записывать в `version_name` версию пакета, признак `dev`, короткий SHA коммита при наличии Git и время сборки в UTC. Числовое поле `version` SHALL совпадать с версией пакета.

#### Scenario: Повторная локальная сборка

- **WHEN** разработчик пересобирает расширение без изменения версии пакета
- **THEN** отображаемая метка содержит новое время сборки, а числовая версия сохраняется.

#### Scenario: Сборка с незакоммиченными изменениями

- **WHEN** рабочее дерево содержит незакоммиченные или неотслеживаемые Git-файлы
- **THEN** метка дополнительно содержит `dirty`.

#### Scenario: Сборка без сведений Git

- **WHEN** исходники собираются вне Git или сведения о коммите недоступны
- **THEN** сборка завершается с меткой `no-git` и временем сборки.

#### Scenario: Подготовка релизной сборки

- **WHEN** выполняется `npm run release:build`
- **THEN** манифест содержит версию пакета без локальной метки.
