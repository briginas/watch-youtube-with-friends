# Design

## Context

Подробности переключаются внутри iframe синхронно. Его высота меняется позже, когда сообщение с замером доходит до вкладки. В промежутке док может сдвинуться или выйти за границу iframe.

## Decisions

- Сделать высоту iframe постоянной между изменениями размера окна и выровнять содержимое по его нижнему краю.
- Ограничить видимую и доступную для мыши область контейнером по фактической высоте панели. При раскрытии и сворачивании менять высоту этой области, сохраняя нижний край. Если сверху тесно, применить существующее ограничение по верхней границе.
- Ограничить высоту подробностей доступной высотой iframe средствами CSS. Действия остаются доступны через прокрутку подробностей.

## Verification

Проверить положение дока между переключением разметки и обновлением контейнера. Проверить работу кликов страницы за пределами панели, прокрутку подробностей и перетаскивание.
