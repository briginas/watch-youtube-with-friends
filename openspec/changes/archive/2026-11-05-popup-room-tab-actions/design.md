# Design

## Context

См. proposal.md. Background хранит изолированные по поколению bindings в storage.session и уже активирует вкладку с фокусом окна. Каталог хранится отдельно в storage.local. Catalog.tsx обновляется только по local storage и не различает положение комнаты.

## Goals / Non-Goals

**Goals:** получить локальное положение комнаты без Auth/REST, сохранить существующую активацию и обработку гонок открытия.

**Non-Goals:** менять формат постоянного каталога или логику read-only входа.

## Decisions

- Ответ `room-catalog/list` дополнить `tabStates` по ключу комнаты (`current`/`other`; отсутствие означает закрытую). Background сопоставляет bindings со списком живых вкладок и active/currentWindow; для каталога как отдельной extension-вкладки — active в окне отправителя. Не сохранять вычисляемые состояния в local: они устаревают при закрытии браузера.
- Catalog обновлять по local/session storage, активации/удалению вкладок и смене фокуса окна; поздние ответы предыдущего чтения игнорировать. Это событийное обновление без нового polling.
- Для текущей комнаты использовать обычный span с приглушённым текстом. Для остальных сохранить operate/activate, изменив только название кнопки. Проверка живой вкладки при самом действии остаётся обязательной при гонке с закрытием.
- Проверки расширяют существующий catalog.spec.ts: настоящий popup через CDP, события вкладок и storage, offline, detached, выход, фокус другого окна. Видеостенд достаточен: взаимодействие с настоящим плеером YouTube не меняется.

## Risks / Trade-offs

- Вкладка может закрыться после чтения → событие обновляет список; существующая activate/open заново проверяет binding.
- Частые session updates → только локальное чтение; обработка последних ответов предотвращает возврат старого состояния.

## Migration Plan

Миграций нет. Backend и persistent storage прежние. Подготовить локальную production-сборку для проверки без публикации.

## Readiness

Ready — источники привязок и механизм активации проверены в коде, новых зависимостей и нерешённых вопросов нет.
