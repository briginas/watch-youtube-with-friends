# Design

## Context

См. proposal.md. Текущий popup — React/CSS Modules; карточка и каталог уже разделены. В `public/icon/` сохранены выбранные иконки, исходник обложки находится в `docs/store-assets/promo-plush-source.png`. Release-аудит разрешает только явно перечисленные ресурсы.

## Goals / Non-Goals

**Goals:** общие CSS-токены двух палитр, сохранение настроек без сетевых запросов, аккуратный popup шириной 400 px с адаптацией к 336 px.

**Non-Goals:** см. proposal.md; системное автоматическое переключение и тема дока не добавляются.

## Decisions

1. Светлая тема — основная по решению пользователя; тёмная меняет только CSS-переменные через `data-theme` у корневого элемента. Это сохраняет состояние React и DOM при переключении. Раздельные компоненты под каждую тему отвергнуты как источник расхождений.
2. Выбор хранится в `browser.storage.local` под отдельным ключом `watch-together:popup-theme:v1`. Он не привязан к backendGeneration: это предпочтение оформления профиля. Чтение до первого React-рендера исключает заметную смену палитры при открытии; отказ чтения обрабатывается. В отличие от localStorage, используется штатное хранилище расширения. Запись по переключателю не меняет session bindings.
3. Переключатель — `button role=switch` с `aria-checked`, постоянным именем «Тёмная тема», подсказкой о действии и видимым фокусом. Сохранение сериализовано; ошибка записи показывается рядом с переключателем и не откатывает палитру текущего документа.
4. Отступы основываются на 24 px снаружи, 16 px внутри карточек, 12 px между связанными элементами. В узком viewport поля уменьшаются до 16 px. Интерактивные элементы не меньше 44 px; длинные названия переносятся; прокрутка сохраняет доступ к подробностям и большим спискам.
5. Выбранная обложка уменьшается в локальный WebP `public/assets/popup-plush.webp`; release allowlist дополняется только этим точным путём. Большой исходник в ZIP не попадает. Иконка загружается из существующего `icon/128.png`.

## Risks / Trade-offs

- Большая иллюстрация оттесняет действия → баннер ограничен высотой 104 px, каталог прокручивается.
- Поведение Chrome action popup отличается от вкладки → browser-тесты проверяют extension origin, реальные размеры, клавиатуру и сохранение; это не проверка живого YouTube или синхронизации.
- Тёмные и светлые поверхности требуют разного контраста → цвета и сообщения проверяются в обеих палитрах, screenshot подтверждает общую компоновку.

## Migration Plan

Миграция комнат не нужна. При отсутствии или неизвестном значении настройки применяется светлая тема. Откат к прежнему popup игнорирует отдельный ключ; backend не меняется.

## Readiness

Ready — существующие assets и storage API доступны; допущение о размерах проверяется browser-тестом до завершения change.
