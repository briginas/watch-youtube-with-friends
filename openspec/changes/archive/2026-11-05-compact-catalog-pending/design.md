# Design

## Context

См. proposal.md. catalogRow уже использует flex без переноса; «Отмена» находится за пределами этого контейнера. busy сейчас также используется для удаления записи.

## Decisions

- Объединить spinner и кнопку отмены в flex-группу без сжатия внутри catalogRow. Название комнаты сохраняет min-width: 0 и доступное пространство.
- Различать открытие и удаление в busy, чтобы не предлагать отмену неотменяемого удаления. Обработчик cancelEntry и сетевую логику не менять.
- Использовать CSS-кольцо и role=status с визуально скрытым описанием. При prefers-reduced-motion отключить вращение.
- Расширить существующую offline-проверку каталога: отсутствие «Подождите…», геометрия при ширине 336 px, доступность отмены и возврат «Открыть».

## Risks / Trade-offs

Длинное имя уменьшает свободное место → группа действий не сжимается, название может переноситься внутри своей колонки.

## Readiness

Ready — изменение локально для разметки; существующий browser-сценарий проверяет сетевую ошибку и последующий успешный вход.
