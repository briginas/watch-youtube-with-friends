# Proposal

## Why

Пользователи с нерусским интерфейсом браузера сейчас видят русские кнопки и сообщения расширения: тексты встроены в popup, session, invitation и общие модули. Английский язык позволит им пользоваться существующим совместным просмотром без изменения сценариев PRD.

## Goals / Success Criteria

- Русский интерфейс Chrome выбирает русский язык расширения; любой другой — английский.
- Popup, плавающая панель, вход по приглашению, ошибки, подсказки и доступные имена используют один язык профиля.
- Пользователи разных языков могут оставаться в одной комнате; названия видео и комнат сохраняются.

## What Changes

- Добавляются полные словари ru/en и английский fallback через Chrome i18n.
- Тексты интерфейса и description manifest заменяются ключами переводов; lang документов соответствует выбранному языку.
- Проверяются локали ru, en и неподдерживаемая локаль, динамические сообщения и узкая вёрстка.

## Non-goals

Ручной переключатель языка, перевод пользовательских названий, локализация внешней страницы Hosting и карточки Chrome Web Store, изменения playback/backend и публикация релиза.

## Capabilities

### New Capabilities

- `extension-localization`: автоматический выбор языка и полная локализация интерфейса расширения.

### Modified Capabilities

Нет: существующие требования оформления и совместного просмотра сохраняются.

## Impact

`public/_locales`, `src/lib/i18n`, entrypoints, session/invitation, общие сообщения ошибок, `wxt.config.ts`, тесты. Новые зависимости, разрешения и поколение backend не требуются.

## Readiness

Ready — пользователь подтвердил реализацию согласованного поведения; источники текстов и механизм Chrome проверены.
