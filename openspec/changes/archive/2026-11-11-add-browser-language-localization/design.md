# Design

## Context

См. proposal.md и specs/extension-localization/spec.md. WXT копирует `public` в пакет; тексты находятся в React, HTML, session/invitation, content scripts, background и общих модулях. Некоторые ошибки сравниваются по русскому префиксу (`background.ts`): такие сравнения необходимо заменить независимой от языка проверкой.

## Goals / Non-Goals

Единый механизм без зависимостей и новых разрешений. Данные Firebase, namespace storage и формат сообщений не меняются. Локализация не добавляет сетевых запросов.

## Decisions

- Нативные `public/_locales/{en,ru}/messages.json`, `default_locale: en`, `i18n.getMessage`. Chrome выбирает локаль и fallback; сторонняя i18n-библиотека не требуется. Название бренда остаётся общим, описание локализуется.
- Типизированный helper принимает ключи словаря и substitutions. Для unit-тестов вне extension runtime используется английский словарь; существующие проверки русских сообщений явно задают русскую локаль в тестовом setup.
- Для соседних подстановок используются именованные Chrome placeholders (`$number$$suffix$`), иначе `$1$2` воспринимается как необъявленная переменная. Статический HTML размечается `data-i18n` и атрибутными ключами, переводится до запуска логики документа. `html.lang` определяется по UI locale браузера и нормализуется до ru/en.
- Общие модули переводят сообщения в текущем extension-контексте. Ошибки передаются как прежде: все контексты одного профиля используют один язык. Машинные коды и сохранённые названия не переводятся.
- Проверки словарей выявляют отсутствующие переводы и несовпадающие placeholders; browser-тесты запускают реальное расширение с разными UI locale, проверяют popup, session и invitation. Существующие русскоязычные UI fixtures явно фиксируют русский язык, чтобы не зависеть от языка машины. На macOS временный launcher задаёт AppleLanguages только тестовому процессу; locale страниц Playwright согласован с ним, фактический getUILanguage проверяется в worker и документах.

## Risks / Trade-offs

- Пропущенные строки или JSX-пробелы → поиск русских литералов вне словарей и проверки реального DOM.
- Более длинный английский текст → узкие viewport и существующие проверки геометрии.
- Browser locale зависит от платформы → в тесте проверять фактический `getUILanguage`, не считать один параметр Playwright доказательством выбора языка Chrome.

## Migration Plan

Миграция данных не нужна; совместимость с текущим backend сохраняется. Сборка для ручной проверки через `release:build`, без публикации и повышения версии в рамках этой задачи.

## Readiness

Ready — механизм Chrome проверен по официальной документации; интеграционные точки определены, блокеров нет.
