# Передача manage-production-generations

Реализация и проверка 27/27 задач завершены 2026-11-04. После паузы по запросу
пользователя работа возобновилась с 3.1. Результаты и условия проверок сохранены
в [verification.md](verification.md).

Live smoke выполнен на существующем QA-проекте `example-qa`
с тестовым control Hosting и поколением `qa-v1`. Production и Store rollout
выполняются отдельно по [runbook](../../../../docs/release.md).
Для настоящей ротации потребуется облачный адаптер. Модель плана и повторы
проверены локально с тестовым адаптером.

Первый rollout использует новый backend и отдельный постоянный control Hosting.
Он укладывается в лимит трёх работающих backend вместе с legacy. При дальнейшей
ротации старейшее поколение определяется по версии первого релиза. Сохранённые комнаты не
мигрируют, legacy-ссылки зависят от старого Hosting. Исходный `.env.production`
сохранён. Соседний change `prepare-public-release` ведётся отдельно.
