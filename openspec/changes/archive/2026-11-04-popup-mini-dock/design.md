# Design

## Context

Popup получает состояние текущей вкладки от session-документа и отдельно загружает локальный каталог. Session-документ уже хранит название и приглашение восстановленной комнаты, в том числе для гостя.

## Goals / Non-Goals

- Воспроизвести выбранный «Мини-док» с компактной строкой и каталогом под ней.
- Оставить управление комнатой, подключение и хранение в существующих компонентах.

## Decisions

- Повторить палитру, размеры кнопок и форму строки дока. Для подробностей использовать нативное раскрытие.
- Дополнить ответ session-документа для popup названием и уже известным приглашением из привязки. Сохранить действующую проверку отправителя.
- В строке показывать состояние связи с комнатой. Состояние локального плеера показывает док страницы.
- Приглашение копировать из popup. При отказе показывать поле только для чтения и выделять ссылку при фокусе.

## Risks / Trade-offs

Длинное название и сообщение об ошибке могут увеличить высоту popup. Названия переносятся, а список комнат сохраняет собственную прокрутку.
