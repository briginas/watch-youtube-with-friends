# Design

## Context

См. proposal.md. Session живёт в cross-origin iframe, выровненном по низу host; host сейчас обрезает iframe по высоте панели. `presentation` передаёт только геометрию и название, а не текст ошибок. Участники скрываются при потере связи.

## Goals / Non-Goals

Сохранить нижнюю привязку и размеры панели, изоляцию extension-документа и существующий алгоритм восстановления. Не добавлять iframe, подключения и зависимости.

## Decisions

- Карточка — абсолютный сосед `room-panel`, источники ошибок и кнопки повторов перенесены в неё. Успех копирования использует ту же отдельную поверхность без оформления ошибки. Ссылка для ручного копирования остаётся только в session.
- Host сохраняет высоту самой панели; iframe с `overflow:visible` у host обрезается `clip-path` по сумме высот панели и выступа карточки. Это ограничивает hit-testing и не меняет bounds host при ошибке. Альтернатива — увеличить host — меняет расчёт drag и заставляет панель прыгать у верхней границы.
- Дополнительное числовое поле `overlayHeight` в presentation описывает выступ карточки. Обратное доверенное сообщение layout передаёт доступную высоту над нижним краем дока; карточка ограничивается этой высотой, при необходимости перекрывая панель. Данные комнаты в layout не входят.
- Закрытие запоминает ключ текущего сообщения, без меняющегося отсчёта повтора. Короткая кнопка поверх иконки дока позволяет открыть сообщение снова. Новая ошибка снимает подавление, её исчезновение очищает ключ.
- Высота блока участников резервируется при временно недоступном presence без показа прежнего состава; строка статуса в заголовке подробностей сохраняет место при ошибках. Длинные тексты не участвуют в размере дока.

## Risks / Trade-offs

- Clip-path и hit-testing OOPIF → проверить реальным Chromium на локальном watch-стенде, включая клики после закрытия.
- Длинное сообщение у верхнего края → прокрутка содержимого карточки, закрытие вне прокрутки, при полном отсутствии места карточку можно закрыть для доступа к доку.
- Изменяющийся countdown → подавление по стабильной причине, а не полному тексту.
- Локальный стенд не подтверждает YouTube → сохранять это ограничение в verification; live-плеер и backend не меняются.

## Migration Plan

Изменение только UI и геометрического контракта текущей сборки; данные не мигрируют. Откат — прежняя сборка. Версия пакета не повышается без задачи выпуска.

## Readiness

Ready — геометрия и источники ошибок изучены; проверяемые гипотезы покрываются браузерными сценариями до архивации.
