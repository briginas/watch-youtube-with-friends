# Verification

Проверено 2026-11-11.

- `npm run typecheck` — успешно.
- `npm test` — 39 файлов, 312 тестов успешно.
- `npm run build:transport` — успешно.
- Chromium с видимым окном и Firebase Emulator Suite: `page-ui.spec.ts`, `panel-position.spec.ts`, `reconnect.spec.ts`, `video-switch.spec.ts` — все 46 сценариев проверены. В общем прогоне прошли 45/46; после исправления предпосылки теста раскрытия повторный прогон всех 7 сценариев `panel-position.spec.ts` прошёл полностью. Код приложения между этими прогонами не менялся.
- Новые браузерные проверки: ошибки clipboard, плеера, смены видео и связи; неизменные bounds панели, дока и host; обе темы и состояния; закрытие, повторное открытие и фокус; сохранение закрытия при обновлении retry; узкий viewport и верхняя граница; прокрутка и клики по странице после закрытия. Playback не изменяется от управления карточкой.
- В тесте раскрытия запас сверху рассчитывается по реальной высоте подробностей, отдельно сохраняется проверка нехватки места. Reconnect-тесты сворачивают подробности, чтобы новая карточка не закрывала controls локального стенда.
- `npm run release:build` — успешно с `.env.production`; сборка для ручной установки: `.output/release/chrome-mv3`, ZIP: `.output/release/watch-together-0.2.8.zip`.
- `openspec validate floating-panel-error-card --strict` и `git diff --check` — успешно перед синхронизацией.
- Delta specs перенесены в основные спецификации; change заархивирован. `npm run spec:validate` — все 9 спецификаций прошли строгую проверку.

Проверки Chromium используют локальный watch-стенд с DOM/media fixture и эмуляторы Firebase. Реальный YouTube и рабочее совместное подключение вручную не проверялись; работа fixture не считается подтверждением live-плеера. У верхней границы карточка может перекрывать часть панели, сохраняя её геометрию и доступное закрытие. Версия пакета не менялась, отправка в Chrome Web Store не выполнялась.
