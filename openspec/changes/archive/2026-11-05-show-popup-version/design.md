# Design

## Context

См. proposal.md и delta spec. Popup использует `browser` из `wxt/browser`; заголовок находится вне условных блоков. В manifest есть числовое `version` и отдельное диагностическое `version_name`.

## Decisions

- Читать `browser.runtime.getManifest().version`, чтобы подпись соответствовала установленному пакету без отдельного источника версии.
- Поместить подпись рядом с `h1` в flex-контейнер с выравниванием по базовой линии. Сохранить текст заголовка и выделить подпись меньшим размером и существующим приглушённым цветом.
- Проверить результат существующим Playwright smoke и геометрией элементов при ширине popup 336px.

## Risks / Trade-offs

Длинная версия может увеличивать ширину → контейнер разрешает перенос, подпись сохраняется целиком. Обычная версия должна помещаться в одну строку; это проверяется браузерным smoke.

## Readiness

Ready — текущая разметка и API manifest доступны; изменения локальны, новых контрактов нет.
