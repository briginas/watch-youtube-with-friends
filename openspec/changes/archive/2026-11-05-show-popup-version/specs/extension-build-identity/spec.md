## ADDED Requirements

### Requirement: Версия расширения в popup

Popup SHALL показывать рядом с заголовком «Смотреть вместе» компактную подпись `v<version>` с числовой версией установленного расширения во всех состояниях popup.

#### Scenario: Открытие popup

- **WHEN** пользователь открывает popup расширения
- **THEN** рядом с заголовком видна подпись с числовой версией из manifest установленного расширения.

#### Scenario: Локальная сборка с диагностической меткой

- **WHEN** пользователь открывает popup локальной сборки с расширенной меткой `version_name`
- **THEN** подпись содержит числовую версию, без SHA, времени сборки и признака `dirty`.

#### Scenario: Неподдерживаемая вкладка

- **WHEN** popup открыт на вкладке без видео YouTube
- **THEN** заголовок и версия остаются видимыми независимо от доступности совместного просмотра.
