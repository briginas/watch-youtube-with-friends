# Proposal

## Why

Пользователю нужно видеть версию установленного расширения прямо в popup: сейчас `src/entrypoints/popup/App.tsx` показывает только заголовок «Смотреть вместе», а версия доступна в деталях Chrome. Это упрощает проверку установленного пакета в рамках существующего MVP из PRD.md.

## Goals / Success Criteria

Рядом с заголовком popup видна текущая числовая версия установленного расширения.

## What Changes

- Добавить компактную подпись версии из manifest рядом с заголовком во всех состояниях popup.

## Non-goals

Изменение номера версии пакета, backend-контракта и метки локальной сборки.

## Capabilities

### New Capabilities

### Modified Capabilities

- `extension-build-identity`: отображение версии установленного расширения в popup.

## Impact

Разметка и CSS popup; существующий Playwright smoke-тест расширения. Новые зависимости не требуются.

## Readiness

Ready — расположение и содержание заданы пользователем; manifest и текущая разметка проверены, блокирующих вопросов нет.
