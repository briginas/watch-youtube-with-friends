# Design

## Context

См. proposal.md и delta `popup-appearance`. `ThemeToggle` сейчас возвращает кнопку и сообщение соседними элементами, CSS сообщения привязан к `.header`. Требуется сохранить нормальный поток сообщения после переноса кнопки.

## Goals / Non-Goals

Сохранить существующее состояние и обработчики темы. Не менять общий appearance storage и UI комнаты.

## Decisions

- Обернуть изображение, переключатель и версию в grid-контейнер. Все три занимают первую ячейку; изображение остаётся 104 px высотой, кнопку выровнять сверху справа с отступом 8 px, версию — снизу справа с тем же отступом. Раздельная верхняя строка отвергнута согласованным макетом.
- Использовать существующие непрозрачные `surface` и `muted` для версии и `surface`/`text` для кнопки: их контраст уже проверяется тестами обеих палитр.
- Сообщение `ThemeToggle` поместить во вторую строку grid, сохранив его состояние и `aria-describedby` без изменения React-компонента. Так ошибка остаётся в потоке и не смещает версию внутри обложки.
- Сохранить имя приложения как скрытый h1 для доступности.

## Risks / Trade-offs

Перекрытие декора и управляющих элементов → проверка геометрии и снимки при 400/336 px в обеих темах. Ошибка сохранения → существующий сценарий отказа плюс проверка сообщения ниже обложки.

## Readiness

Ready — локальные React/CSS изменения, хранение и протоколы не затронуты; гипотеза размещения проверяется браузерными тестами.
