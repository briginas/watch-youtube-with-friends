# Proposal

## Why

В popup верхняя строка с иконкой, заголовком, версией и темой занимает 64 CSS px вместе с отступом (`App.module.css`). Пользователь одобрил макет, который освобождает это место для комнаты и каталога; сценарии совместного просмотра из PRD не меняются.

## Goals / Success Criteria

- Popup начинается с прежней обложки, без отдельной строки брендинга.
- Тема доступна справа сверху на обложке, версия — справа снизу; обе темы читаемы при ширине 400 и 336 CSS px.
- Сохранение темы, клавиатура и действия комнаты продолжают работать.

## What Changes

- Удаляем видимые иконку и заголовок popup и отдельную верхнюю строку.
- Переносим существующий переключатель и версию на обложку с подложками из палитры темы.
- Сообщение об ошибке сохранения темы размещаем под обложкой.

## Non-goals

Изменение плеера, транспорта, хранения, плавающей панели, выпуск в Store и повышение версии.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `popup-appearance`: компактная обложка с темой и версией вместо верхней строки.

## Impact

`src/entrypoints/popup/App.tsx`, `App.module.css`, браузерные проверки popup. Новые зависимости и миграции не нужны.

## Readiness

Ready — пользователь одобрил макет и реализацию; существующие компоненты и требования проверены.
