## MODIFIED Requirements

### Requirement: Создание комнаты из текущего видео

Система SHALL создавать комнату по действию «Смотреть вместе» на поддерживаемой странице видео и сохранять текущее видео, позицию, скорость и состояние воспроизведения. Доступность действия MUST определяться текущей страницей вкладки, включая переход к видео внутри YouTube без перезагрузки документа.

#### Scenario: Создание из открытого видео

- **GIVEN** пользователь открыл обычное записанное видео на YouTube
- **WHEN** пользователь нажимает «Смотреть вместе» в popup
- **THEN** создаётся комната с состоянием текущего плеера
- **AND** пользователь получает ссылку-приглашение

#### Scenario: Первое подключение после SPA-перехода

- **GIVEN** расширение работает в документе главной страницы или поиска YouTube
- **WHEN** пользователь переходит к поддерживаемому видео без reload и открывает popup при доступном сервере
- **THEN** подключение завершается и действие «Смотреть вместе» становится доступным без перезагрузки вкладки
- **AND** тот же сценарий работает независимо в новой вкладке

#### Scenario: Повторное открытие popup

- **GIVEN** первое подключение после SPA-перехода завершилось
- **WHEN** пользователь закрывает и повторно открывает popup
- **THEN** popup использует прежнюю сессию вкладки без дополнительного session-документа

#### Scenario: Текущая страница вне просмотра

- **WHEN** пользователь открывает popup на главной странице или странице поиска YouTube
- **THEN** popup предлагает открыть обычное видео и не запускает сессию создания комнаты
