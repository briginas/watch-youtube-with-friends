## Результат

Совпадений по перечисленным шаблонам и непубличным значениям окружения не найдено. Встроен Firebase Web API key и публичные настройки QA-проекта `example-qa`. Сам API key в отчёт не включён. Manifest содержит только `activeTab`, `clipboardWrite`, `storage`; host permissions — два YouTube origin и QA Hosting. Иконок нет, версия `0.0.0`.

Firebase прямо описывает Web API key как публичную клиентскую конфигурацию: безопасность доступа обеспечивают Auth, Rules и ограничения API key. Это не разрешение включать service account, приватный ключ или токены. [Официальное описание](https://firebase.google.com/docs/projects/api-keys).

## Ограничения

Это статическая проверка известных форматов, а не доказательство отсутствия всех возможных секретов. Архив ZIP ещё не создан; production-проект, его настройки API key/Rules и будущий пакет не проверялись. История Git, runtime IndexedDB, сетевой трафик и browser storage не сканировались. В runtime расширению необходимы пользовательские Auth-токены и секреты принятых комнат; они должны оставаться в доверенном extension-контексте и не передаваться YouTube или сторонней диагностике. Повторить аудит непосредственно на финальном ZIP с привязкой к его SHA-256.
